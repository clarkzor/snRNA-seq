# Validation

This folder contains repository/pipeline checks and lightweight run summaries.
It is separate from biological figures and tables under `results/`.

Run static validation from the repository root:

```bash
Rscript scripts/validate_repository.R
```

This checks repository structure, parses R scripts, and validates the annotation-rule schema.
It does **not** execute Seurat/Signac analyses or prove that external input data are available.

A build-time report is included for the downloadable bundle. Runtime files such as
`input_summary.csv`, `package_versions.csv`, `sessionInfo.txt`, and
`annotation_validation_summary.csv` are generated by the analysis.
